# সোনার গাঁ (Sonar Gaon)

A quick village-building board game in Bengali. Roll the die, collect rice, fish and bamboo, build huts and houses. First to 8 points wins.

Modes: play the computer, two players on one phone, or send a link to a friend and play turn by turn (no server needed, the game state is inside the link).

## Publish on GitHub Pages
1. Create a new public repository on github.com (for example `sonar-gaon`).
2. Upload every file in this folder (drag and drop works), including `.nojekyll`. Commit to the `main` branch.
3. Open **Settings → Pages**. Under "Build and deployment", set **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**. Save.
4. After a minute your game is at `https://YOUR-USERNAME.github.io/sonar-gaon/`
5. Privacy policy page: `https://YOUR-USERNAME.github.io/sonar-gaon/privacy.html`. Edit `privacy.html` first and replace `[YOUR EMAIL ADDRESS]`.
